# shef.problems
Отвечает за учёт проблем в Битрикс24|БУС.

> Подключает библиотеку [Monolog](https://github.com/Seldaek/monolog) для создания своих логгеров

# Настройка
1. В настройках указываем сотрудников на каждую роль
2. Опционально настраиваем [ротацию логов](docs/5_logrotate.md)
